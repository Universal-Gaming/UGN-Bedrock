These are browser-reported capabilities, not a benchmark of Minecraft simulation. A smooth diagnostic animation does not guarantee high Minecraft FPS.

SAFE TROUBLESHOOTING

The lightweight preference only controls UGN's animated homepage; it cannot change the upstream Minecraft engine's FPS. In-game, lower render distance, simulation distance, particles and graphics settings. Compare singleplayer against multiplayer to identify relay/server lag. Never clear site storage as a first troubleshooting step—browser worlds may be stored there.

IN-GAME TESTER MODE

While actually playing a world, press Ctrl+Shift+F8 to open the optional UGN performance monitor. Play for 30–60 seconds, then save the local report to compare frame pacing across worlds and devices. Press Escape first if mouse capture prevents interacting with the report button. The overlay is a frame monitor, not a game-server ping detector.

ABOUT NETWORK LAG

The website test measures the trip to this GitHub Pages site, not to a Minecraft server, relay, or world host. Actual multiplayer ping and packet jitter require a connected game/relay and cannot be truthfully inferred from this page.

If singleplayer runs smoothly but multiplayer rubber-bands, check the chosen WebSocket relay and Minecraft server TPS/MSPT. If both modes stutter, investigate FPS, WebGL and browser memory first.
