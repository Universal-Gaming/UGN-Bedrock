UGN Java packages the independently developed, MIT-licensed Minecraft Web Client behind a custom interactive space-themed page. This project is not the official Minecraft Java client and does not distribute Eaglercraft's original game port.

As of November 18, 2026, official Minecraft Java is at version 26.3. The integrated browser client's advertised support is 1.8–1.21.5, so 26.3 multiplayer and its new blocks are not yet available. The public website does not require a Microsoft account. Multiplayer on compatible offline-mode servers requires a separate WebSocket-to-TCP relay and strong username protection; online-mode authentication is a separate flow.

The independent client may save worlds or preferences to your browser. Review its separate data handling before public launch.
