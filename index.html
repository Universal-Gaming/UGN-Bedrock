UGN uses an independently developed MIT-licensed Java-compatible browser client, presented inside a custom UGN animated 3D homepage. This is not the official Minecraft Java client or an APK emulator.

Currently advertised support is Java 1.8–1.21.5. The newest official 26.3 features are not supported yet. UGN Java multiplayer needs a secure separately hosted relay and compatible server. You can set up your own featured UGN endpoint in the project configuration.

The homepage does not request Microsoft account credentials. The independently developed game runs on this website in its own browser page, so mouse capture doesn't rely on an iframe. Its local settings and world data remain managed by the client.
