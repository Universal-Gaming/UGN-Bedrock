This 3D UGN website loads a separate, real browser-native Java Edition-compatible client compiled from the MIT-licensed Minecraft Web Client project. The client must first be built and deployed in /client/. Supported versions and features depend on that upstream implementation.

The self-hosted client supports singleplayer and compatible Java servers. Multiplayer needs a separately hosted secure WebSocket-to-TCP gateway; UGN's existing newer-version servers might exceed the client's current protocol support. Microsoft login belongs to the upstream client and must be audited for your preferred session-only token policy before production.
